# KPI Engenharia — Excel/VBA

Projeto de portfólio em **Excel habilitado para macros (`.xlsm`)**, voltado à organização e acompanhamento de indicadores operacionais relacionados a engenharia, horas e compras.

![Excel](https://img.shields.io/badge/Excel-KPI%20%26%20Automation-217346?logo=microsoftexcel&logoColor=white) ![VBA](https://img.shields.io/badge/VBA-Automation-867DB1) ![Portfolio](https://img.shields.io/badge/Portfolio-Project-0A66C2)

## Arquivo principal

`KPI_ENGENHARIA.xlsm`

Por ser um arquivo habilitado para macros, a melhor experiência é abrir no **Microsoft Excel Desktop** e habilitar o conteúdo apenas se você confiar no arquivo.

## O que este projeto demonstra

- uso de Excel como ferramenta de apoio à gestão;
- estruturação de indicadores e controles operacionais;
- automação de tarefas com VBA;
- organização de informações para acompanhamento gerencial;
- aplicação de tecnologia a rotinas administrativas e de compras.

## Contexto de portfólio

Este repositório foi organizado para apresentar um trabalho prático desenvolvido em Excel/VBA. O objetivo é mostrar capacidade de transformar uma necessidade operacional em uma ferramenta de controle e acompanhamento.

> Para avaliação técnica, abra o arquivo `KPI_ENGENHARIA.xlsm` no Excel Desktop e navegue pelas abas, indicadores e automações disponíveis.

## Segurança

Arquivos `.xlsm` podem conter macros. Antes de habilitar macros, revise o código VBA e utilize o arquivo em um ambiente confiável.
